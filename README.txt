CYBERGUARD INSTALLABLE WEB APP (PWA)

WHAT THIS PACKAGE IS
This is an installable Progressive Web App version of CyberGuard. It is not an Android APK file.
It keeps your HTML/CSS/JavaScript app and adds the files needed for home-screen installation and offline caching.

IMPORTANT
For installation on Android, the files must be hosted at an HTTPS address (localhost is also allowed for testing).
Opening index.html directly from a file manager will not enable PWA installation.

SIMPLE DEPLOYMENT
1. Extract this ZIP on your computer.
2. Upload all files/folders to a static hosting service that provides HTTPS, for example GitHub Pages or Netlify.
3. Open the published HTTPS website on your Android phone in Chrome.
4. Tap Chrome's three-dot menu and choose "Install app" or "Add to Home screen" (wording varies).
5. Confirm. CyberGuard should appear on your home screen and open in a standalone window.

APK REQUIREMENT
If your college specifically requires an .apk file, this PWA ZIP alone is not an APK. You must use an online WebView-to-APK builder or an Android build service to package the hosted website. Do not upload private messages or personal data to third-party builders.

SECURITY NOTE
CyberGuard uses simple local pattern matching. Its score is educational and cannot guarantee that a URL or message is safe or malicious. Never enter real passwords or OTPs into scam examples.
